# 말하기 시험 통합 평가 시스템 최종 버전

## 포함 기능
- 시험 시행, 생각하기/말하기 타이머
- 말하기 중 '제출' 버튼: 현재까지 녹음한 답안을 제출
- 기존 녹음 파일 업로드
- 직접 녹음 또는 업로드 파일로 AI 보조 채점
- AI 평가와 교사 평가 비교
- AI 점수를 교사 평가로 복사
- 교사 평가 최종 확정
- 결과 엑셀(.xlsx) 저장
- 결과 JSON 저장

## 적용 방법
1. ZIP 압축을 풉니다.
2. GitHub speaking01 저장소의 기존 파일을 이 파일들로 교체합니다.
3. Netlify에서 Deploys → Trigger deploy → Deploy project를 누릅니다.
4. 환경변수는 기존 값을 유지합니다.


## 수정 사항
- 업로드/녹음 파일을 OpenAI 전사 API로 보낼 때 파일 확장자가 유지되도록 수정했습니다.
- webm, mp3, wav, m4a, ogg 형식 인식을 보완했습니다.
