# 말하기 시험 자동 채점 보조 시스템

## 포함 기능
- 응시자 화면: 시험 시작, 지시문 공개, 생각하기 1분 30초, 말하기 2분, 말하기와 동시에 자동 녹음
- 관리-교사 화면: 응시자명 입력, 녹음 재생·다운로드, 수동 점수 입력, 자동 등급 산출
- AI 보조 채점: 녹음 파일 전사 후 과제 수행·언어·전달 점수 추천
- 결과 JSON 저장

## 등급 산출 로직
- 과제 수행 1~3점
- 언어 1~3점
- 전달 1~2점
- 총점 7~8점: 7급
- 총점 6점: 6급
- 총점 5점: 5급
- 총점 3~4점: 4급

## Netlify 배포
1. 이 ZIP 파일을 풀어 GitHub 저장소에 업로드합니다.
2. Netlify에서 New site from Git을 선택합니다.
3. Environment variables에 다음을 설정합니다.
   - OPENAI_API_KEY: OpenAI API 키
   - TRANSCRIBE_MODEL: gpt-4o-transcribe
   - SCORE_MODEL: gpt-5.5-mini
4. 배포 후 사이트 주소로 접속합니다.

## 주의
AI 채점은 교사용 보조 의견입니다. 실제 판정은 교사가 전사와 녹음, 루브릭을 확인해 확정하는 방식으로 운영하는 것이 안전합니다.
