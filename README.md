# 말하기 시험 통합 평가 시스템 - 고급 비대면 교육 루브릭 반영판

## 반영 내용
- 과제 수행 0~3점
- 표현 0~3점
- 전달 0~2점
- 총점 7~8점: 7급
- 총점 6점: 6급
- 총점 5점: 5급
- 총점 0~4점: 4급

## 주요 기능
- 직접 녹음 시험 시행
- 말하기 중 제출 버튼
- 기존 녹음 파일 업로드
- AI 보조 채점
- AI 평가와 교사 평가 비교
- 교사 평가 최종 확정
- 결과 엑셀 저장
- 결과 JSON 저장
- AI 채점 진행률 표시
- 새 시험/새 파일 업로드 시 평가 결과 자동 리셋

## 적용 방법
1. ZIP 압축을 풉니다.
2. GitHub 저장소에 파일을 업로드하여 기존 파일을 덮어씁니다.
3. Netlify에서 Deploys → Trigger deploy → Deploy project를 누릅니다.
4. 환경변수는 기존 값을 유지합니다.
   - OPENAI_API_KEY
   - TRANSCRIBE_MODEL = gpt-4o-transcribe
   - SCORE_MODEL = gpt-4o-mini


## 추가 수정 사항
- AI 채점 근거 및 피드백에 과제 수행 3개, 표현 3개, 전달 2개 상위요소별 O/△/X 판단과 근거를 표시합니다.
- 엑셀/JSON 저장에도 상위요소별 AI 판단값을 포함합니다.
